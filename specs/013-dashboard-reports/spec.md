## 1) لوحة التحكم

### الموجود ✅ (يبقى كما هو)
`Dashboard.tsx` — إجمالي الموكلين · إجمالي القضايا · الجلسات القادمة · القضايا المضافة حديثاً.

### الناقص من §1.1 (يُضاف كبطاقات جديدة)

| المطلوب في الوثيقة | الإضافة |
|---|---|
| **عدد القضايا حسب الحالة** | مخطط دائري: مفتوحة · معلّقة · محجوزة للحكم · مغلقة — قابل للنقر للتصفية |
| الجلسات القادمة | ✅ موجود — يُضاف عدّاد "اليوم / هذا الأسبوع" |
| **المهام المتأخرة** | بطاقة حمراء بعدد المهام المتأخرة + قائمة أعلى 5 |
| **الإيرادات والمصروفات** | بطاقتان + مخطط أعمدة لآخر 6 أشهر + صافي الربح |
| **العقود المنتهية** | بطاقة العقود المنتهية والمنتهية خلال 30 يوماً (من 004) |
| **إشعارات النظام** | ويدجت آخر 5 تنبيهات (من 008) |

### إضافات مفيدة
- مواعيد اليوم (من 007) · فواتير مستحقة (من 005) · نشاط الفريق الأخير (من `auditLogs`)
- **لوحة مخصصة لكل دور:** المحاسب يرى المالية · المحامي يرى قضاياه · السكرتارية ترى الجدول
- **ترتيب الويدجت بالسحب** وحفظ التخطيط لكل مستخدم

## 2) التقارير

### الموجود ✅ (يبقى)
`Reports.tsx` — المقبوضات · صافي الربح · الإيرادات مقابل المصروفات شهرياً · توزيع القضايا · أداء المحامين · طباعة.

### الناقص من §1.11

| التقرير المطلوب | الحالة |
|---|---|
| تقارير القضايا | 🟡 جزئي → تفصيل بالنوع والمحكمة والحالة ومدة الإغلاق ونسبة الكسب |
| أداء المحامين | ✅ موجود → يُضاف: ساعات مفوترة · إيراد لكل محامٍ · معدل الإنجاز |
| الإيرادات | ✅ موجود |
| **العملاء** | ➕ جديد: الأكثر ربحية · التوزيع الجغرافي · معدل التحصيل · العملاء الخاملون |
| **العقود** | ➕ جديد: بالحالة والنوع والقيمة · معدل التجديد · متوسط مدة الاعتماد |
| **الجلسات** | ➕ جديد: عدد ونتائج · معدل التأجيل · التوزيع على المحاكم |
| **المتأخرات** | ➕ جديد: أعمار الديون (من 005) |
| **الحضور والإجازات** | ➕ جديد (من 010) |
| **سجل التدقيق** | ➕ جديد: تقرير نشاط المستخدمين |

### التحسينات المشتركة
- **تصدير PDF** بالعربية RTL مع ترويسة المكتب (حالياً طباعة فقط + Excel في `Accounting.tsx`)
- **فلاتر موحّدة:** مدى تاريخ · محامٍ · عميل · محكمة · نوع قضية · حالة
- **مقارنة الفترات:** هذا الشهر مقابل السابق، مع نسب التغيّر
- **جدولة التقارير:** إرسال دوري بالبريد (عبر 008)
- **صلاحيات التقارير** حسب المصفوفة: مدير المكتب والشريك **كامل** · المحامي والمستشار **الخاصة به** · السكرتارية **محدودة** · المحاسب **مالية** · العميل **الخاصة به**
- **الأداء:** تجميعات محسوبة مسبقاً (`report_aggregates/{lawyerId}/{period}`) بدل جلب الكولكشنات كاملة عند كل فتح
