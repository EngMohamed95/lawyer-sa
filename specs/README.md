## 4. المراحل والجدول الزمني

### 🔴 المرحلة 0 — إيقاف النزيف الأمني (أسبوع 1) — **إلزامية قبل أي عميل حقيقي**

الميزة **001** فقط. لا يُبنى أي شيء آخر قبل اكتمالها.

الثغرات المُغلَقة:
1. قواعد Firestore المفتوحة (`allow read, write: if request.auth != null` على كل شيء)
2. `upload.php` بلا مصادقة ولا فلترة امتدادات → رفع Webshell
3. مسارات Express بلا أي مصادقة — بما فيها `PUT /api/users/:uid/password`
4. `VITE_GEMINI_API_KEY` مكشوف داخل حزمة الواجهة
5. الدور مقروء من `localStorage` → ترقية ذاتية للصلاحيات
6. مفتاح SSH خاص بصيغة نصية على القرص
7. التسجيل الذاتي مفتوح في Firebase Auth

**بوابة الخروج:** اختبار اختراق داخلي يثبت أن مستخدم مكتب (أ) لا يستطيع قراءة أي بايت من بيانات مكتب (ب).

### 🔴 المرحلة 1 — الأساس (أسابيع 2–4)
**002** ثم **003**. تُبنى مصفوفة الصلاحيات وسجل التدقيق وسلة المحذوفات ونظام إدارة الحسابات.

### 🟠 المرحلة 2 — الوحدات الغائبة الكبرى (أسابيع 5–10)
