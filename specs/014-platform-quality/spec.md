## المتطلبات

### R1 — بنية الاختبارات
```
tests/
├── unit/          منطق الصلاحيات · الضرائب · التواريخ · الترقيم
├── rules/         قواعد Firestore و Storage
├── api/           تكامل كل مسار (مصادقة · صلاحية · عزل · تحقق مدخلات)
└── e2e/           مسارات المستخدم الحرجة (Playwright)
```
الأدوات: `vitest` · `@firebase/rules-unit-testing` · `supertest` · `@playwright/test`

**الهدف:** ≥70% تغطية لمنطق الصلاحيات والمالي · 100% لقواعد Firestore.

مسارات E2E الحرجة: دخول بكل دور · إنشاء قضية كاملة · رفع مستند · إصدار فاتورة وتحصيلها · دورة اعتماد عقد · إنشاء مستخدم مكتب · عزل المستأجرين.

### R2 — CI/CD بوابات إلزامية
```yaml
# .github/workflows/ci.yml  (جديد — deploy.yml القائم يبقى)
- npm ci
- npm run lint              # tsc --noEmit — يجب 0 أخطاء
- npm run test:unit
- npm run test:rules
- npm run test:api
- npm run build
- npm audit --audit-level=high
# النشر لا يبدأ إلا بعد نجاح كل ما سبق
```
+ حماية الفرع الرئيسي: مراجعة إلزامية · منع الدفع المباشر · فحص أسرار (`gitleaks`).

### R3 — البحث الشامل
تفعيل مربع البحث المعطّل (Q3): بحث موحّد في القضايا والعملاء والمستندات والجلسات والمهام والعقود والفواتير،
مع اختصار `Ctrl+K` ونتائج مجمّعة بالنوع، ومقيّد بـ `lawyerId` وصلاحية المستخدم.

### R4 — الأداء
- Pagination على كل القوائم (حجم 25، تمرير لانهائي أو ترقيم)
- إزالة `limit(100)` الصامت واستبداله بجلب تدريجي مع مؤشر واضح
- تقسيم `CaseDetails.tsx` و`Documents.tsx` إلى مكوّنات فرعية (**بلا تغيير أي سلوك**)
- تخزين مؤقت للبيانات المرجعية
- **الهدف:** LCP < 2.5s · حجم الحزمة الأولية < 300KB مضغوطة

### R5 — التجربة والموثوقية
- استبدال كل `alert()` بنظام `Toast` موحّد
- `ErrorBoundary` لكل صفحة مع رسالة عربية وزر إعادة محاولة
- `Skeleton` بدل "جاري التحميل..." النصي
- حالات فارغة مصمّمة لكل قائمة
- تفعيل "نسيت كلمة المرور؟" (Q4) عبر `sendPasswordResetEmail`
- تأكيد قبل مغادرة نموذج غير محفوظ

### R6 — أمان الأنواع
- تفعيل `strict: true` في `tsconfig.json` تدريجياً ملفاً ملفاً
- `src/types/` بأنواع مشتركة لكل الكيانات (تُشتق من نفس المصادر في الخادم)
- إزالة `any` من الكود الجديد إلزامياً

### R7 — المراقبة
- Sentry (أو مثيله) للواجهة والخادم مع إخفاء البيانات الشخصية
- تسجيل منظم على الخادم + تتبع زمن الاستجابة
- تنبيه عند ارتفاع معدل الأخطاء

### R8 — المكتبة القانونية (Q12)
نقل البيانات الثابتة إلى `legal_library/` في Firestore مع بحث وتصنيف وتحديث،
و**الإبقاء على المصفوفة الحالية كبيانات أولية (seed)**.
